# First year video game made with Pygame
 "Your only move is draw" is a smash-bros like fighting game set in the scoarching deserts
                    of the wild west. The two stickmans face each other in a duel.
                    Be fast, strike quicky and use the unique traits of the characters to knockout your opponent from the area!

## My role

I was in charge of the network, sound design, UI and organization of the project.
